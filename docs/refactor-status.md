# 重构质量与前端对照状态

评估日期：2026-10-29。基准为 `main` 的 `81a41bd014c9d7ee2ec0cd50e9d43fff58c2b8f5`；本轮通过 `git ls-remote` 确认 GitHub main 仍指向该提交。工作分支为 `codex/modular-refactor`，没有合并 main、打标签或部署。

## 当前判断

维护结构已经成型：Worker 按契约、领域规则、用例、端口和适配器分层；前端、统一 API 客户端和语义样式独立。程序只有一套，源码为 `app/`，Worker 入口为 `app/src/index.ts`，浏览器源码为 `app/web/`。同一次构建生成 Cloudflare 静态资源，Worker 处理 `/api/*`；构建产物不提交。

使用真实浏览器截图比较，替代“布局断言通过就等于完整复刻”的判断。最新四种宽度、十七个固定状态共 68 组对照中，53 组逐像素完全相同，所有截图尺寸相同。空配置共 12 组中 11 组零差异，375px 空配置中心有 16 个阴影边缘像素不同。严格视觉命令仍返回失败；不能宣称整站完美复刻或严格无障碍全部通过。

## 工程质量收尾

- Linux CI 曾在四种宽度报导航高度偏差。根因是重构页面额外的 42px 最小高度；移除后，显式小行高浏览器回归从 42／34px 失败转为一致。修复提交 `9bebbe4` 的 [Linux CI 已通过](https://github.com/231128ikun/DDNS-cf-proxyip/actions/runs/40844186269)。后续工程改动仍需核实其最终提交的 CI。
- `useBatchCheck` 接管批量检测输入、进度、中断、续检和旧请求失效，`app.tsx` 从 848 行减至 689 行；没有改动展示流程，也没有增加运行依赖。
- 远程文本网络交互移到 HTTP 适配器，通过 `RemotePoolSource` 注入；应用层保留统一池清洗。通知模板移至任务边界，避免任务直接依赖发送适配器。
- 新增 13 项架构门禁测试，遍历实际源码的 AST；约束导入、再导出和动态导入，阻止核心层引入基础设施、页面绕过客户端或引入后端实现。四种旧池格式增加真实客户端、Worker、应用与内存 KV 的读写闭环。
- [架构说明](architecture.md) 和 [发布验收与回退说明](release-readiness.md) 已落地。真实 Cloudflare 环境仍未部署、验收，文档没有将模拟测试视为实际环境通过。

## 本轮修改

- 修正此前遗漏的空配置状态：移除额外跳转按钮，没有维护域名时隐藏无用的 DNS 添加行，恢复 main 的目标摘要、空绑定表格行与启动警告。空配置提示恢复单列宽度和内容高度，移除整行展开和 120px 最小高度。
- 新增 `audit:ui:main` 实时基准回归检查。严格 `audit:ui` 保留原有对比度和 32px 高度要求；CI 改为禁止相对 main 新增或恶化，已知问题仍逐项报告。没有修改产品配色、控件尺寸或数值阈值。
- 审计只计算实际可见元素，不再把关闭折叠区的内容或彩色 emoji 当作普通可见文字；基准也识别旧页面的内联点击控件。按功能块和内容构造唯一身份，身份重复或基准缺失直接失败，不允许用同名控件或总数量互相抵消。

此前对齐已经保留：

- 恢复 main 的配色、字体、行高、间距、控件、状态徽标、表格、页脚与控制台排版。视觉参数仍来自同一份 `styles.css`，没有引入另一套样式或运行依赖。
- 对齐配置字段与说明顺序、权限编辑器、帮助区、池菜单、池与绑定排序弹窗、TXT 展示及登录页。保留统一配置保存、凭据掩码和原生弹窗的键盘焦点约束。

## 功能与构建验证

本轮最终代码的 `npm run check` 通过：类型检查、36 个测试文件中的 298 项契约、单元与架构测试、正式构建、体积门禁、Wrangler 本地部署形态冒烟均通过。冒烟验证静态首页、健康接口、单目标探测、缺失资源与未知 API 的 JSON 404。没有放宽预算。

当前 gzip 体积：Worker 36.53 KiB／60 KiB，前端 JS 与 CSS 合计 43.69 KiB／50 KiB。前端 JS raw 合计 98.61 KiB／100 KiB，余量较小。本轮没有增加依赖或放宽体积预算。

`audit:parity` 在 375、768、992、1440px 均通过，最终报告时间为 `2026-10-29T08:54:44.313Z`。覆盖配置草稿、切页、取消、统一保存、失败重试、还原、运行参数、解析、复制、模拟 DNS 增删、排序、鉴权和批量续检。排序还覆盖长名称、长列表、取消、焦点归还和读取恢复；鉴权覆盖错误与正确密钥及地址栏密钥清理；续检覆盖已完成地址不重复请求与结果元数据保留。配置、绑定和池读写经过真实客户端、同次构建 Worker 和内存 KV；外部探针、DNS 与通知使用替身。

严格 `audit:ui` 仍失败：main 的部分配色与小控件不满足文字对比度和至少 32px 高度要求。六种宽度均无页面横向溢出，交互失败、无名称控件、重复 ID 和缺少替代文本均为零。`audit:ui:main` 使用同一浏览器、同一空配置数据和六种宽度实时审计两侧，对比度及宽高均不得恶化，新增违规也失败；它通过不等于严格无障碍通过。

七项比较器测试覆盖继承问题、改善、对比度下降、文字要求提高、任一尺寸缩小、问题替换、歧义身份、遍历顺序变化和基准缺失。空配置交互断言覆盖摘要、多余控件、绑定表格、启动日志与占位卡尺寸。另用默认池为零地址的本地服务器验证 `--base` 完成 12 组页面审计，避免固定等待虚构池数量；严格模式仍报告遗留失败。CI 执行 `audit:ui:main && audit:parity`；远端 CI 是否通过须以 GitHub 实际运行结果为准。

在 `app/` 下复现：

```sh
npm run check
npm run audit:ui
npm run audit:ui:main
npm run audit:parity
npm run audit:visual
# 对已有的确定性截图重新比较，不重新采集：
npm run audit:pixels
```

功能与布局报告位于 `app/.wrangler/tmp/ui-parity/`，无障碍报告位于 `app/.wrangler/tmp/ui-audit/`，main 实时对照位于 `app/.wrangler/tmp/ui-audit-main/`。功能断言通过不能替代严格视觉结果。

## 维护保障与未验证范围

接口契约通过真实 `ApiClient -> Worker route -> application` 覆盖逐地址检测、并发上限、进度、最终合并、A/AAAA 端口、TXT 地址端口、检测上限和取消。配置覆盖旧格式、环境回退、KV 优先、部分更新保留与运行参数边界；探针异常保持 `unknown`，不得因此删除 DNS 或入桶。一键洗库使用服务端用例，垃圾桶只有统一写入入口，通知数量基线仅在通知成功后更新。IP 池设计见 `ip-pool-design.md`。

十七个截图状态与已有交互回归没有穷举所有悬浮、焦点、筛选组合、生产数据、跨窗口并发及网络时序。无障碍实时基准覆盖空配置的两个页面，不代表所有弹窗及数据状态均已审计。实际部署环境的静态资源绑定、Cookie 和 Cloudflare KV 可见性尚未验证。没有调用真实 DNS 删除、KV 清空、垃圾桶清空或全量维护，也没有部署。
